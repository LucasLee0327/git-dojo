# git-dojo 設計書（唯一真相來源）

瀏覽器內的 Git 團隊協作練習場：模擬 AI 助手＋真的 git 狀態機＋假 GitHub＋即時預覽的小專案。
給學生團隊新成員熟悉協作規範（分支、PR、衝突、審查、指揮 AI）用。

> 本 repo 公開。所有內容**去識別化**：不寫真實組織名、repo 名、內部路徑。
