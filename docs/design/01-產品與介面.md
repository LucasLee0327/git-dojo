# 01 產品與介面

## 定位

- 對象：學生團隊的開發成員與部長，Git 新手，平常主要透過 AI agent 操作 Git。
- 目標：親手經歷「開分支 → commit → push → PR → 衝突 → 審查 → 合併 → 上線」，熟悉協作規範中**需要人判斷**的部分，並學會攔下 AI 的危險操作。
- 與團隊協作手冊的關係：並存。手冊負責看圖理解，本站負責動手練習。

## 任務列與任務卡（2026-10-14 追加）

- **🗺 流程地圖**：任務列上、📖 規則速查旁的按鈕，開啟一張純 HTML／CSS 的小圖（流程、六個名詞、「暫存區」與「staging 分支」同名的提醒、AI／人的分工）。第 0 關的任務卡另外內嵌一份，預設展開，可收合。不是必修頁面。
- **分階段的任務卡**：關卡可以定義 `stages`，把目標分成有名字的階段（目前只有第 1 關：A–D）。任務卡在每組目標上方顯示階段標題與一句「為什麼」；目前階段標色、完成的階段打勾；任務卡收起來時，單行提示前面也會標出目前階段。沒有 `stages` 的關卡照舊平鋪。
- **規則速查**：上方註明 G／P／R／A／§ 是這個團隊的約定；另有「Git 本身的機制」一節。

## 常駐的 git 狀態面板（2026-10-14 追加）

讓玩家隨時看到「現在的 git 狀態」，跟之後在 VS Code 裡看到的對得上。

- **常駐顯示**：不能只放在分頁裡。分支圖和狀態摘要要一直看得到（可以收合，但預設展開）。終端機或 AI 每執行一個指令，就即時更新並有動畫。
- **狀態摘要**（仿 VS Code 的 Source Control 面板）：目前分支（或 detached HEAD）、相對 upstream 的 ↑ahead ↓behind、已暫存／未暫存／未追蹤的檔案清單、衝突中的檔案、是否正在 merge。
- **分支圖**（仿 VS Code 的 Source Control Graph：直式、最新在上）：
  - **每條分支一個顏色**。同一條分支在圖、標籤、終端機提示字元、GitHub 頁面上都用同一個顏色。
  - **節點不能和線重疊**：線不可穿過與它無關的節點；節點畫在線的上層，外圈留背景色的空隙；分支要分配到不同的欄位（lane）。
  - 分支標籤顯示在對應的 commit 旁邊，本機分支和 `origin/…` 用不同樣式；HEAD 有「你在這裡」標記。
  - 保留手冊模擬器的圖例：實心＝已經在 GitHub 上，空心虛線＝只在本機；squash 合併用灰色虛線標出內容的來源。
  - 可以切換視角：**你的電腦**（預設，和 VS Code 看到的一樣，`origin/…` 是上次 fetch 時的狀態）／**GitHub 實際狀態**／**小美的電腦**。藉此教「沒 fetch 之前，你看到的 origin 是舊的」。

## 互動規則

- **終端機**：手打 git 指令；輸出照真 git 的英文原文，下方附中文解說。
- **AI 助手**：玩家從 2–4 個選項中選一句話送出。選項顯示的就是實際送給 AI 的句子；其中可能有刻意模糊、會讓 AI 走捷徑的壞選項。
- **AI 的危險操作**（模擬 Auto 模式＋團隊權限規則，見 02 第二部）：
  - 碰到 `deny` 規則或 Auto 本身會擋的操作：畫面顯示「已擋下」，AI 改走別條路。
  - 碰到 `ask` 規則：跳出權限視窗（允許／拒絕／告訴它怎麼做）。
  - 其他操作：AI 直接執行，玩家只能靠讀它的輸出、隨時按 **Esc** 打斷。
  - 不管哪一種，選錯了都真的會發生，後果會出現在分支圖、預覽和 GitHub 上；之後可以「時光倒流」回到選擇之前。
- **組員小美**：機器人，依劇本在特定時間點 push、開 PR。
- **過關判定**：檢查最終狀態，任何合法路線都算。
- **🧑「看過」類任務要有證據**（2026-10-14）：打開 PR 的 Files changed／Checks／預覽站（GitHub 頁的「預覽站」分頁，或預覽分頁的「PR 預覽」）時，遊戲記下 `{ PR 號, 分頁, 當時 head commit }`；任務必須在 PR **目前的** head 看過才打勾，PR 後來又有新 commit 就要重看（已合併的 PR 以合併當下的 head 為準，所以合併後回去補看也能打勾）。按 Ready／送審查／合併**不會被擋**，只是缺證據時跳警告（橫幅，可時光倒流）、該格不打勾、關卡不過關。每個任務各自宣告需要哪些分頁（例：第 1 關 Ready 要 Checks＋Files＋預覽；第 8 關 `look` 是任何一版看過即可，`merged` 要在小美修好後的 head 重看）；不是全域鎖。
- **提示**：三段式（方向 → 指令 → 直接示範）。

## 存檔

- 存在 localStorage，每個動作後自動存；重新開啟時顯示「繼續上次進度」。
- 會遺失的情況（要在網站上說明）：無痕視窗、清除網站資料、換電腦或換瀏覽器。
- 不做後端，也不做完成證書。
